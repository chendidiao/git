# L0 工具层学习清单

> 目标（2 周后达到）：能打开 AI 生成的项目 → 装依赖 → 跑起来 → 浏览器看到页面 → 改一行代码看到变化 → 报错时能看懂并贴给 AI。
>
> 环境：Windows + PowerShell

## 1. 命令行 10 条（第 1-3 天）

VS Code 里按 `` Ctrl+` `` 打开内置终端（就是 PowerShell），逐条敲，观察输出：

| # | 命令 | 作用 | 试一下 |
|---|------|------|--------|
| 1 | `pwd` | 显示当前在哪个目录 | 敲完看输出 |
| 2 | `ls` | 列出当前目录的文件 | 在随便哪个目录敲 |
| 3 | `cd 文件夹名` | 进入文件夹 | `cd Desktop` 试 |
| 4 | `cd ..` | 退回上一级 | 配合上一条用 |
| 5 | `mkdir 名字` | 新建文件夹 | `mkdir test` 然后 `ls` 看 |
| 6 | `code .` | 用 VS Code 打开当前目录 | 在 test 目录里敲 |
| 7 | `cp 文件 新名` | 复制文件 | `cp a.txt b.txt` |
| 8 | `mv 文件 新名` | 移动/重命名 | `mv b.txt c.txt` |
| 9 | `rm 文件` | 删除（**小心，没有回收站**） | 删你刚建的 c.txt |
| 10 | `clear` | 清屏 | 敲完看 |

**必会的三个技巧**：
- 上/下箭头 = 翻历史命令
- Tab 键 = 自动补全路径（打 `cd Des` 按 Tab）
- `Ctrl+C` = 中断卡住的程序

> ⚠️ 记住：`rm` 删了不经过回收站，练习时只在 test 文件夹里玩。

## 2. Git 增删改回退（第 3-7 天）

**安装**：git-scm.com 下载 Git for Windows，一路默认安装。

**第一次配置**（只做一次）：
```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

**核心流程（4 个命令）**：
```powershell
git status          # 看当前状态——最常用，随时敲
git add .           # 把修改放入「暂存区」
git commit -m "做了什么事"   # 存档（写清说明，方便回退）
git log --oneline   # 看存档历史
```

**回退（3 个命令）**：
```powershell
git checkout -- 文件名    # 丢弃还没 commit 的修改
git reset --hard HEAD~1   # 回退到上一个存档（已提交的也能回）
git branch                # 看分支；git checkout -b 实验 建新分支
```

**🎯 30 分钟练习（第一天就做）**：
1. `mkdir gitlab && cd gitlab && code .`
2. `git init`
3. VS Code 里新建 `hello.txt`，写几个字，保存
4. 终端：`git add .` → `git commit -m "第一个存档"`
5. 把 hello.txt 内容改成乱码
6. `git checkout -- hello.txt` → 打开看，**内容回来了**
7. 完成这个循环 = Git 最核心的「存档-改坏-回退」你已经会了

**和 AI 协作的铁律**：让 AI 动手改代码前，先 `git commit` 一个存档点。改坏了就回退——这是你的安全网。

## 3. VS Code（第 1-3 天顺带）

- 安装后装插件：**Chinese (Simplified)**（中文界面）、**Prettier**（格式化，AI 代码乱时右键格式化）
- 只学五件事：
  1. File → Open Folder 打开项目
  2. 左边资源管理器看文件树
  3. `Ctrl+F` 文件内搜索，`Ctrl+Shift+F` 全项目搜索
  4. `` Ctrl+` `` 打开内置终端
  5. `Ctrl+S` 保存
- 不学：调试器、快捷键大全、主题美化

## 4. 浏览器 DevTools（第 4-7 天）

网页上按 `F12` 打开。**只学三个面板**：

**Console（最重要）**
- 红字 = 报错，开发时 90% 的问题从这里看到
- 练习：打开任意网页 → F12 → Console → 输入 `1+1` 回车 → 显示 2
- `console.log(变量)` 是 AI 调试时最常用的工具，学会看它输出

**Application**
- 左边找 **IndexedDB** —— 你的账本数据就存在这里（哈希链、记录）
- 以后检查「数据到底存没存进去」就看这里
- 顺手认识 Local Storage / Session Storage

**Network**
- 看网页发起的网络请求：点一个请求 → 看 Status（200=成功，404=找不到，500=服务器炸了）
- Phase 2 调 API 时全靠它

## 5. AI 工具（第 8-14 天）

**你现在用的环境就是 Claude Code 类的工具**——已经在用了。补三个习惯：

1. **先打开项目目录再提问**——AI 能看到代码才能改对
2. **描述要具体**：不是「帮我修 bug」，是「打开页面报错：XXXX，点提交按钮后控制台显示 XXXX，期望是 XXXX」
3. **让 AI 当老师**（最关键的用法）：
   - 选中代码 → 「逐行解释这段在干嘛」
   - 「给所有代码加中文注释」
   - 「这段用了什么我不懂的概念？用 C++/Python 类比给我讲」

**🎯 第一周周末练习（完整体验生成→运行→修改循环）**：
1. 打开 Cursor（cursor.com 下载）或直接用本环境
2. 让 AI：「写一个计算器网页，单个 HTML 文件，能加减乘除，中文界面」
3. 用 VS Code 打开 → 右键 HTML 文件 → Open with Live Server（装 Live Server 插件）
4. 浏览器里玩计算器 → 改一个按钮颜色 → 刷新看变化
5. 让 AI：「加一个清零按钮」→ 看它怎么改 → 保存刷新
