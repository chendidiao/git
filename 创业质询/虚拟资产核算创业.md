# 虚拟资产核算创业

> **一句话定位**：面向三角洲行动搬砖玩家 → 工作室 → 金商的记账工具，核心交付物是**「兑换比例证明」**——让每一笔哈夫币↔人民币的兑换有据可查。免费记账获客，专业版订阅变现。

## 核心交付物：兑换比例证明

**为什么是它**：哈夫币无官方汇率 → 税务确认收入（收入 = 哈夫币量 × 汇率）时，**实际成交记录就是唯一证明**。被查自证的成败全在汇率证据是否连续、完整、可审计。

**组成**：
- 每笔交易记录：哈夫币量 / **派生汇率**（= 哈夫币量 ÷ RMB，自动算）/ RMB 金额 / 渠道（商行·交易行·线下）/ 商行名 / 时间 / 流水号 / **账号条件（训练中心/安全箱/靶场/刀皮/封禁记录）**——汇率合理性的佐证 / 备注（可挂截图）
- 汇率历史：用户自己成交汇率的曲线 + 手动录入的商行报价
- 证明文件导出（PDF）：按期间汇总（哈夫币总量 × 实际汇率 = RMB 收入）+ 每笔明细 + 免责声明

**边界**：只记录实际成交，不内置建议汇率；市场参考区间（1:36-40）只作为内容营销素材，不进产品。

**汇率理论框架（实物黄金类比，三层结构）**：
- 实物黄金：国际金价（LBMA/COMEX 公开价格发现）→ 美元汇率换算 → 国内溢价/零售加价，三层全部公开可审计 → 这就是黄金「可证明」的根本
- 哈夫币对应：① **锚定层（成本地板）**= 打金时间成本 × 时薪（搜打撤：哈夫币 = 游戏时长产物）② **换算层（官方锚）**= **不存在**（官方无兑换渠道，玩家一手确认）③ **市场层（成交价）**= 商行报价（供需/账号质量/风险溢价）→ **哈夫币只有市场层**，黄金三层的「可证明性」只能靠用户自己的成交记录补齐
- **合理汇率区间 = [用户自填时间成本地板, 用户历史成交上界]** → 工具可做「汇率合理性提示」：不内置任何市场价，只基于**用户自己录入的历史成交分布**做异常标记（如某笔偏离自身历史均值 ±20% 提示确认）——数据全部来自用户，守住纯工具边界

**底层汇率逻辑（引擎设计，2026-08-15 定稿：单轨制）**：
- **汇率事实（玩家一手确认）**：三角洲是搜打撤类型，哈夫币是搜刮过程产物——**官方没有任何购买/兑换渠道**（「多玩就有」）→ 汇率只有一条轨：**场外市场轨**（商行成交，2026 年行情约 1 元 = 36-44 万哈夫币，**≥1:42 踩黑币风险线**）
- **汇率来源**：完全无官方锚 → 兑换比例的唯一证据 = 用户自己的实际成交记录（聊天记录/转账/商行报价）→ 工具存在理由最大化
- **核心原则：汇率是派生值不是输入值**——每笔交易只记「哈夫币量 + 人民币金额」，汇率 = 哈夫币量 ÷ RMB 自动派生。少一个输入负担、汇率与交易自洽、每笔汇率的出处就是那笔交易（可审计）
- **数据模型**：交易记录字段：账号 / 渠道（商行·交易行·线下）/ 哈夫币量 / RMB 金额 / **派生汇率** / 收款账户 / 流水号 / 账号条件 / 时间戳 / 凭证截图
- **引擎规则**：① 账号维度校验：某笔汇率偏离该账号历史均值 ±20% → 标黄提示（数据全来自用户，纯工具行为）② 时间维度：汇率漂移是常态（2025: 1:10-12万 → 2026: 1:36-44万），统计带时间窗口 ③ 合理性区间（仅提示）：[时间成本地板, 用户历史成交上界]——两端皆用户数据 ④ **冷启动**：前 5-10 笔无历史均值，不做偏离提示
- **边界**：不内置任何外部市场数据（含 44 万:1 与 1:36-40 万区间）；外部行情只用于内容营销
- **证明输出三层**：逐笔明细（含派生汇率 + 凭证）→ 期间汇总（卖金收入 / 买金支出，按渠道与账号汇总）→ 汇率说明页（账号条件 + 汇率口径声明「汇率由实际成交自动派生，未内置任何外部汇率」+ 免责声明）

## 存证机制（三个技术要件，2026-08-15 定稿）

**① 哈希值校验（防篡改）**
- 每条记录写入时计算 SHA-256 摘要，**链式连接**：`hash_n = SHA256(record_n + hash_{n-1})`——篡改任何历史记录都会断链
- 每周/每 N 条生成「**链头快照**」，可导出保存（用户本地/云盘/打印）
- 「完整性校验」一键重算全链，输出校验报告
- 纯前端实现（WebCrypto + IndexedDB），**免费版即有**

**② 权威时间戳（第三方锚定）**
- 接入联合信任 TSA（[国家授时中心共建、我国唯一权威 TSA，RFC 3161 API](https://www.tsa.cn/openservice.html?type=2)，需商务申请）
- 时机：**导出证据包时**把链头哈希送 TSA，费用 **10 元/次**，用户按次自付（低频刚需：10 元 vs 数千-数万赔偿/罚款）
- 证明逻辑：链头在 T 时刻即已存在 → 事后任何修改都与 TSA 凭证矛盾
- 免费版：无 TSA，只有本地哈希链（防篡改但无权威时间锚）

**③ 与原始凭证关联（证据链完整性）**
- 每笔记录挂载凭证（截图/聊天记录/转账记录/商行报价），**凭证 SHA-256 入链**（换图即断链）
- 「**证据包**」导出物 = 证明文件 PDF + 凭证副本 + 凭证哈希清单 + 哈希链校验报告 + TSA 时间戳凭证 + 使用说明（证据规范指引，不含法律意见）
- 证据包导出后**用户自持**（本地/云盘/打印），工具不代为保管——隐私与责任边界

**边界**：工具不承诺法律效力，只提供符合电子数据证据规范（[《人民法院在线诉讼规则》](https://www.gov.cn/zhengce/202505/content_7022513.htm)16-19 条：时间戳/哈希/区块链存证的真实性审查规则）的记录与导出；最终采信由法院/税务机关决定

**公证**：挂起为 v2 候选（线上公证自助指引：公证云等平台 + 公证友好导出格式；正式公证处合作等有付费用户后再谈）

## 数据飞轮：成交记录的获取（2026-08-15）

**核心认知：记录无法「获取」，只能「换取」**——成交记录是税务敏感私有资产；爬虫（军备竞赛+灰区）和买商行数据（不是用户的证据链）皆不可行 → 用价值交换记录。

**三阶段策略**：
1. **验证期**：2-3 个工作室/金商的几十笔真实流水（脱敏）——访谈时直接要「最近一周的收金卖金记录」，研究真实字段形态（汇率怎么报、用什么凭证）
2. **产品期**：导入机制降低交记录成本（手动/CSV 先行，插件 v1.1）
3. **飞轮期**：「记录换行情」机制

**聚合行情机制（定稿）**：
- 上传字段（脱敏）：渠道 / 哈夫币量 / 派生汇率 / 账号条件——**不含账号 ID、收款账户、金额明细**
- 免费层：**个人汇率对照**（「你最近汇率高于 73% 的用户」）——上传动机强，免费版不膨胀
- 专业层：**全量聚合行情**（成交汇率分布 / 渠道对比 / 黑币风险线）——付费理由
- 合规：数据 100% 来自用户自己 → 不违反「不内置外部数据」边界；人越多行情越准 → 飞轮成立
- 冷启动：数据池 ≥几百笔才有统计意义 → 访谈样本 + 创始人自己（玩家）的记录打底
- 隐私信任：明确脱敏规则 + 用户可删除自己的数据

## 关键事实（已查证）

### 税务量级逻辑
- **增值税**：小规模纳税人月销售额 10 万以下免征 → 普通搬砖党（月流水 500-5000）远低于起征线，**无税务风险、无付费动机**
- **个税**：经营所得需成规模才触发稽查；税务机关风险模型看**总量 + 频率**，不看单笔
- [元宝案](https://chinackts.com/taxcases/886.html)真相：单笔仅 300 元，但**单季度总量 1020 万**（3.5 万笔订单）才被查 → 判例支持的是「成规模的持续经营」
- 推论：**付费层必须是有总量的人**——工作室（1-10 万/月）和金商（5-50 万+/月）
- 关键前提：**游戏货币无官方兑换汇率** → 「兑换比例证明」只能由实际成交记录构成 → 这正是工具存在的理由

### 三角洲行动生态（2026-08-15）
- 哈夫币汇率：约 **1元 ≈ 36-40万哈夫币**（1000万哈夫币 ≈ 30元）；头部商行报价 1:35.8-40，**报价 ≥1:42 基本是虚假引流/黑币**
- **汇率形成机制**：官方不开放哈夫币↔人民币兑换 → 场外市场自发形成，无官方锚点，受五因素影响：① 打金成本（时间成本是地板）② 供需（版本/赛季波动：2025 年 1:10-12 万 → 2026 年 1:36-41 万）③ **账号质量**（训练中心等级/安全箱格数/靶场等级/刀皮/封禁记录——好账号 1:36，差账号 1:42）④ 风险溢价（黑币/封号，1:42+ 基本是黑货）⑤ 官方钻石锚（10钻=100万哈夫币 ≈ 1:10万，场外更便宜）
- **核算边界（用户一手确认）**：金条等游戏道具**不是**重要核算内容——单件价值极低（30 万哈夫币/根 ≈ 7 角），道具只是哈夫币的产出途径（摸金所得 → 交易行换币），**RMB 侧核算只有两件事：卖金（哈夫币→人民币）、买金（人民币→哈夫币）**；游戏内道具↔哈夫币转换不进账（无人民币发生额）
- **推论：汇率是个性化的** → 兑换比例证明必须带**账号条件**字段作汇率合理性佐证
- 官方交易行受限：每日额度（流通建议 ≤2000万/日）、手续费上升、单 IP 最多 3 账号 → **场外商行卖金是主流变现路径**
- 商行生态：[竞也商行、皮猴电竞、龙也商行等](https://m.163.com/dy/article/KSDC6GAI0556LLWV.html)头部玩家，大量[商行测评/避坑内容](https://www.360kuai.com/pc/detail?parse_short_url=1&u=99bbc63e6a35c2190d3eb3995f99f0e28b4)在活跃传播
- 风险：黑币/脏币（触发风控封号）、虚假汇率引流、商家跑路；S9 赛季官方反黑产专项整治、风控收紧 → **黑币追溯是金商/工作室的真实焦虑**
- 搬砖方式：摸金跑刀搜物资（单局 80-150万哈夫币）、时间差倒卖、钥匙卡套利、组队刷精密零件、代肝/护航

### 竞品格局
- **三角洲记账工具：空白**（已查证，无现成记账/价格/汇率工具）→ 无竞品威胁，但需教育市场
- 对比 CS2：那边有免费竞品 cs2-trade-manager 已占位，这边是干净场地

### 合规红线（不变）
- 纯记账工具 ≠ 涉税服务（安全区）；税务咨询需实名+信用码+信息报送；专业顾问/合规计划必须机构资质；代申报需报送委托协议
- 虚拟支付：2026-04-01 起小程序全终端虚拟交易必须走虚拟支付专用通道，禁止外链跳转；iOS 抽成 12%；个人主体不可开通任何支付

## 风险清单

1. **假设证伪（已发生一次）**：玩家量级税务付费不成立 → 付费层已切到工作室/金商；**工作室访谈结果需在 Phase 2 开工前回收**，否则二次烂尾
2. **证明有效性依赖用户如实记录**：工具只记录、不背书；若用户录入的是假汇率假流水，证明文件在税务上无效（免责声明 + 引导挂真实凭证截图）
3. **市场教育成本**：竞品空白 = 无人验证过付费意愿，需要内容投入教育「成规模卖金要留账」
4. **政策双刃剑**：官方反黑产整治/税务稽查收紧 → 痛点放大，但工具本身可能被波及（坚持纯工具边界 + 免责声明，不预判资金来源）
5. **游戏热度周期**：三角洲行动热度下滑 → 用户流失（比 CS2 的资产保值性更脆）
6. **业余时间拖延**：两阶段交付纪律是防烂尾的唯一护栏
