# 反三角函数

反三角函数是三角函数的**反函数**,由于三角函数在其整个定义域上不单调,须限制在某个单调区间内取反函数,此区间对应的值称为**主值分支**。

- $y=\arcsin x \iff x=\sin y,\ y\in[-\pi/2,\pi/2]$
- $y=\arctan x \iff x=\tan y,\ y\in(-\pi/2,\pi/2)$

其图像可看作对应三角函数(主值区间内那段曲线)关于直线 $y=x$ 对称的图形。

## 性质总表

| 函数 | 定义域 | 值域 | 奇偶性 | 单调性 | 渐近线 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| $\arcsin x$ | $[-1,\ 1]$ | $[-\pi/2,\ \pi/2]$ | 奇函数 | 递增 | 无 |
| $\arccos x$ | $[-1,\ 1]$ | $[0,\ \pi]$ | 非奇非偶 | 递减 | 无 |
| $\arctan x$ | $(-\infty,\ +\infty)$ | $(-\pi/2,\ \pi/2)$ | 奇函数 | 递增 | $y=\pm\pi/2$ |
| $\arccot x$ | $(-\infty,\ +\infty)$ | $(0,\ \pi)$ | 非奇非偶 | 递减 | $y=0,\ y=\pi$ |
| $\arcsec x$ | $(-\infty,-1]\cup[1,+\infty)$ | $[0,\pi/2)\cup(\pi/2,\pi]$ | 非奇非偶 | 两支均递增 | $y=\pi/2$ |
| $\arccsc x$ | $(-\infty,-1]\cup[1,+\infty)$ | $[-\pi/2,0)\cup(0,\pi/2]$ | 奇函数 | 两支均递增 | $y=0$ |

## 常用特殊值

| $x$ | $0$ | $\dfrac{1}{2}$ | $\dfrac{\sqrt2}{2}$ | $\dfrac{\sqrt3}{2}$ | $1$ |
| ---- | ---- | ---- | ---- | ---- | ---- |
| $\arcsin x$ | $0$ | $\pi/6$ | $\pi/4$ | $\pi/3$ | $\pi/2$ |
| $\arccos x$ | $\pi/2$ | $\pi/3$ | $\pi/4$ | $\pi/6$ | $0$ |

| $x$ | $0$ | $\dfrac{\sqrt3}{3}$ | $1$ | $\sqrt3$ | $+\infty$ |
| ---- | ---- | ---- | ---- | ---- | ---- |
| $\arctan x$ | $0$ | $\pi/6$ | $\pi/4$ | $\pi/3$ | $\pi/2$ |

## 恒等式

- $\arcsin x+\arccos x=\dfrac{\pi}{2}$
- $\arctan x+\arccot x=\dfrac{\pi}{2}$
- $\arcsec x+\arccsc x=\dfrac{\pi}{2}$(取主值分支时成立)
- 奇函数性质:$\arcsin(-x)=-\arcsin x$,$\arctan(-x)=-\arctan x$,$\arccsc(-x)=-\arccsc x$

## 导数公式

| $f(x)$ | $f'(x)$ | 条件 |
| ---- | ---- | ---- |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ | $\lvert x\rvert<1$ |
| $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^2}}$ | $\lvert x\rvert<1$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ | $x\in\mathbb{R}$ |
| $\arccot x$ | $-\dfrac{1}{1+x^2}$ | $x\in\mathbb{R}$ |
| $\arcsec x$ | $\dfrac{1}{\lvert x\rvert\sqrt{x^2-1}}$ | $\lvert x\rvert>1$ |
| $\arccsc x$ | $-\dfrac{1}{\lvert x\rvert\sqrt{x^2-1}}$ | $\lvert x\rvert>1$ |

> [!tip] 记忆技巧
> 反三角函数的导数与原三角函数导数互为倒数,并出现"负号"的是 $\arccos x$ 与 $\arccot x$(其主值区间内单调递减);出现 $\lvert x\rvert$ 的是 $\arcsec x$ 与 $\arccsc x$(定义域含两支)。
